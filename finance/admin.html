Entrar

¿Cómo saco mi llave? (una sola vez)
  1. Entra a github.com › Settings › Fine-grained tokens › Generate new token.
  2. Nombre: «Panel ARXO Finance». Expiración: 1 año.
  3. En Repository access elige Only select repositories y marca arxo-web.
  4. En Permissions › Repository permissions › Contents elige Read and write.
  5. Toca Generate token, cópialo y pégalo arriba. Se guarda solo en este navegador.
